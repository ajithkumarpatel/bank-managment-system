Bank Management System
The Bank Management System is a Python-based application designed to automate and manage banking operations like account creation, deposits, withdrawals, balance checking, and transaction history tracking. Using MySQL as the database and SQLAlchemy for ORM (Object-Relational Mapping), this system provides a simple yet effective solution for managing a bank's day-to-day operations.

Features:
Account Creation: Allows users to create new bank accounts with required details such as name, account type, and an initial balance.
Deposit: Users can deposit money into their accounts, which is automatically reflected in the balance.
Withdrawal: Users can withdraw funds from their accounts, with checks to ensure that the balance is sufficient.
Balance Enquiry: Allows users to view their current account balance at any time.
Transaction History: Keeps track of all transactions (deposits, withdrawals, transfers) made within an account.
Account Deletion: Provides functionality for deleting a bank account when required.
Technologies Used:
Programming Language: Python
Database: MySQL
ORM: SQLAlchemy (for easy interaction with MySQL)
